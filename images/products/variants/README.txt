AFRIGADGETS COLOUR VARIANT IMAGES

Place colour-specific device pictures in this folder.

Example files:
iphone17-black.png
iphone17-white.png
iphone17-mist-blue.png

Then reference the filename as the third value in the colour entry in:
js/shared/product-variants.js

Example:
["Black", "#171717", "iphone17-black.png"]

The customer only sees these choices after opening View Details.
